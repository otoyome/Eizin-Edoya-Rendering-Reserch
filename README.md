画家の鈴木英人さんとイラストレーターの江戸屋犬八さんの絵を参考にして、  
NPR表現を研究していたものになります。  
ただ、画像で使用したモデルは再配布禁止モデルを利用していたため、このプロジェクトでは環境は再現できないです。  
自作モデルとSponzaにたいしてシェーダーを適応しただけのものになります。

実装内容  
・通常のシャドウマップではセルフシャドウが汚かったため、セルフシャドウを消しつつ影を出すため、影専用ライトを実装してキャラクターのみ別で処理しています。  
・シェーディング時にG-Bufferに対してシェーディング用の情報を保存し、  
　それを基にして  
　・ライティング時にベースカラーと影用カラーを内積結果を使ってどちらを使うかを決めています。  
　　その際に、ポスタライズを行って階調化しています。  
　・キャラクターのみ、通常のシャドウマップによるセルフシャドウは行っていませんが、  
　　コンタクトシャドウを使って、セルフシャドウを表現しています。  
　・ポストプロセス時に情報を読み込んで、輝度差と法線/深度差を元にしてラインを引いています。  
　　また、英人特有のノイズを輝度値の低い所に乗せています。
